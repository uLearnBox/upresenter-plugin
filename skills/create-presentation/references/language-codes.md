# Language codes for `setPresentationLanguage`

`setPresentationLanguage {languageCode}` sets the player's buttons, the date format and the text
direction. It does not translate the content. Use the code of the deck's language; for a language
not listed, take the closest one (the player interface then falls back to English).

| Code | Language | Code | Language | Code | Language |
|---|---|---|---|---|---|
| `en-US` | English | `vi-VN` | Vietnamese | `zh-CN` | Chinese Simplified |
| `zh-TW` | Chinese Traditional | `ja-JP` | Japanese | `ko-KR` | Korean |
| `es-ES` | Spanish | `fr-FR` | French | `de-DE` | German |
| `pt-BR` | Portuguese (Brazil) | `it-IT` | Italian | `nl-NL` | Dutch |
| `ru-RU` | Russian | `uk-UA` | Ukrainian | `pl-PL` | Polish |

| `ar-EG` | Arabic (RTL) | `he-IL` | Hebrew (RTL) | `fa-IR` | Persian (RTL) |
| `ur-PK` | Urdu (RTL) | | | | |

Also available: `bg-BG`, `hr-HR`, `sr-RS`, `sk-SK`, `sl-SI`, `lt-LT`, `lv-LV`, `et-EE`.

Right-to-left languages mirror the slide (text alignment, list and answer order). Look at the
slides afterwards. For a full translation of an existing deck use the `localize-presentation`
skill if it is installed.
